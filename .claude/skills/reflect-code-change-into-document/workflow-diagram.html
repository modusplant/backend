Skill workflow

reflect-code-change-into-document

Updates the Claude documentation (CLAUDE.md, rules, documents, skills) that corresponds to each changed class.

Skill file: .claude/skills/reflect-code-change-into-document/SKILL.md. That file is the source of truth; this page is a human-oriented view of it.

Step, in run order Document read File written External system Terminate or skip Branch or fallback Repeated per item
  1. 1

    Resolve Target Classes

    Collect every .java class not yet pushed: uncommitted changes (git status --porcelain) combined with committed-but-unpushed ones (git diff against the upstream, or origin/main if none).

    The combined list is empty.
  2. 2

    Classify each class

    Using the package layout in CLAUDE.md, find the section each class belongs to before checking any document.

    Read.claude/CLAUDE.mdClassification basis: top-level packages, domain names, and infrastructure areas.
  3. 3

    Update the mapped documents

    For each class, update the documents mapped to its category below.

    Category → documents to update
    CategoryDocuments
    Domain sub-module under domains (e.g. member, search).claude/CLAUDE.md, plus any relevant file under .claude/documents/, .claude/rules/, or .claude/skills/
    Other top-level package (e.g. infrastructure, shared).claude/CLAUDE.md, plus any relevant file under .claude/documents/ or .claude/rules/
    No domain, Docker-related (e.g. docker-compose.yml).claude/skills/guide-docker-environment-configuration/SKILL.md only
    No domain, Grafana-related (e.g. src/main/resources/logback-spring.xml).claude/documents/observability-tagging-architecture.md only
    Write.claude/{CLAUDE.md, documents/, rules/, skills/}Only the documents mapped above.
    Necessary-only: change strictly what is needed. No extra examples, and no content duplicated within a document or across documents.

Guardrails

  • Runs only when invoked by .claude/skills/postprocess-main-code-change/SKILL.md, never on its own initiative.
  • Edits under src/** are disallowed.
